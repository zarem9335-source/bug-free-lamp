# EKTS اندروید — مدار فرمان + هوش مصنوعی (جاوا — نسخه ۲)

برنامه‌ای شبیه **EKTS** (شبیه‌ساز مدارهای فرمان الکترومکانیکی) برای اندروید،
**کاملاً با زبان جاوا** نوشته شده است — بدون کاتلین.
همه قابلیت‌های ETKS را دارد و چند قابلیت پیشرفته‌تر و آسان‌تر هم به آن اضافه شده است.

> نسخه ۲ — جاوا، JDK 17، Gradle 8.7، Android SDK 34.
> شبیه‌سازی آن منطق نردبانی (Ladder) مدار فرمان است، نه SPICE کامل.

## همه قابلیت‌های ETKS — که این برنامه دارد

ETKS از این‌ها تشکیل شده بود: کتابخانه گروه‌بندی‌شده، جابه‌جایی و چرخش قطعه،
نام‌گذاری قطعه‌ها، تنظیم زمان تایمر، رنگ لامپ، ذخیره/باز کردن فایل،
خروجی عکس، لیست قطعه‌های استفاده‌شده، پیدا کردن خطا، و سیستم‌های آماده
(آسانسور ۵ طبقه و دو سیستم گیت). همه این‌ها اینجاست:

| قابلیت ETKS | در این برنامه |
|---|---|
| تغذیه AC تک‌فاز و سه‌فاز | فاز L، نول N، برق سه‌فاز 400V، فیوز، کلید سه‌پل |
| قطعه‌ها: کنتاکتور، رله، تایمر وصل/قطع، شستی، کلید، کنتاکت NO/NC، لیمیت سوئیچ، لامپ | همه + رله جدا، شستی Jog، آژیر/بازر |
| موتور القایی تک‌فاز و سه‌فاز | موتور سه‌فاز + موتور تک‌فاز |
| سیستم‌ها: آسانسور، گیت ۱ و ۲ | آسانسور بالا/پایین، درب اتوماتیک (گیت)، + پمپ با فلوتر، سه موتور ترتیبی |
| نوع‌های مدار موتور (۹ نوع در ETKS) | مستقیم، ستاره-مثلث، چپ‌گرد/راست‌گرد، تک‌فاز، استارتر مقاومتی، تایمر، لامپ |
| جابه‌جایی قطعه | کشیدن روی بوم + چسبیدن به شبکه ۵۰ واحدی |
| چرخش قطعه | دکمه «⟳ چرخش» — ۹۰ درجه در هر ضربه |
| نام‌گذاری قطعه | دکمه «✎ مشخصات» — نام، زمان تایمر، رنگ لامپ |
| تنظیم زمان تایمر | در «مشخصات» — ۰٫۵ تا ۶۰ ثانیه، برای هر تایمر جدا |
| رنگ لامپ | در «مشخصات» — قرمز / سبز / زرد / آبی |
| ذخیره / باز کردن فایل | «ذخیره» + «مدارهای من» (چند مدار با نام) |
| خروجی عکس | دکمه «🖼 PNG» — در گالری > EKTS ذخیره و قابل اشتراک است |
| لیست قطعه‌های استفاده‌شده | دکمه «لیست قطعات» (BOM) |
| پیدا کردن خطا | دکمه «✓ بررسی خطا» — اتصال کوتاه، کنتاکت بدون بوبین، نام تکراری، قطعه بی‌سیم |
| اجرا و کنترل با شستی | دکمه ▶ اجرا؛ شستی را نگه دار، کلید ضامن است |
| زبان فارسی | رابط کاربری فارسی است (ETKS هم فارسی داشت) |

## پیشرفته‌تر و آسان‌تر از ETKS

- **جای‌گذاری با ضربه:** قطعه را از پایین انتخاب کن، بعد روی بوم ضربه بزن تا همان‌جا قرار بگیرد — لازم نیست وسط صفحه بیفتد و بعد بکشی.
- **جستجوی قطعه:** در کادر جستجو «تایمر» یا «موتور» را بنویس تا پالت فیلتر شود.
- **Undo / Redo:** دکمه‌های ↩ برگرد و ↪ جلو — تا ۵۰ قدم.
- **زوم:** دکمه‌های + / − زوم روی بوم.
- **انیمیشن جریان:** در حالت اجرا، جریان با نقطه‌های زرد روی سیم‌های برق‌دار حرکت می‌کند و سیم برق‌دار قرمز می‌شود.
- **بررسی خطا قبل از اجرا:** اگر اتصال کوتاه یا کنتاکت بدون بوبین باشد، اجرا شروع نمی‌شود و خطا را نشان می‌دهد.
- **ماشین‌حساب برق:** قانون اهم (V/I/R/P) و توان موتور سه‌فاز `P = √3 × V × I × cosφ`.
- **راهنمای قدم‌به‌قدم:** بار اول که برنامه باز می‌شود راهنما می‌آید؛ دکمه «؟ راهنما» همیشه هست.
- **هوش مصنوعی (صفحه جدا):** دستور فارسی بده، مدار رسم می‌شود — چیزی که ETKS نداشت.
- **ذخیره دائمی API — لازم نیست هر بار وارد کنی:** پایین را ببین.

## هوش مصنوعی — لیارا و اوا (AvalAI) + ذخیره API

صفحه جدا هوش مصنوعی با دکمه 🤖 باز می‌شود. هر دو ارائه‌دهنده با پروتکل
OpenAI-Compatible کار می‌کنند: درخواست به `{Base URL}/chat/completions`
با هدر `Authorization: Bearer <کلید>`.

### ذخیره API — یک بار وارد کن، برای همیشه می‌ماند

- کلید، Base URL و مدل **برای هر ارائه‌دهنده جدا** ذخیره می‌شود
  (اوا، لیارا، OpenAI، سفارشی — هر کدام کلید خودش را دارد).
- ذخیره با این‌ها انجام می‌شود: دکمه «💾 ذخیره تنظیمات»، دکمه «ارسال به هوش مصنوعی»،
  و خروج از صفحه هوش مصنوعی — یعنی حتی اگر یادت رفت ذخیره را بزنی، با ارسال یا خروج هم ذخیره می‌شود.
- با باز شدن صفحه، ارائه‌دهنده آخری که استفاده کرده‌ای + کلید و آدرس و مدلش خودکار برمی‌گردد
  و زیر کادر کلید نوشته می‌شود: «✓ تنظیمات … ذخیره شده (تاریخ و ساعت) — لازم نیست دوباره وارد کنی».
- دکمه «نمایش کلید» / «پنهان کن»، دکمه «پاک کردن کلید» و دکمه «تست اتصال» هم هست.
- کلید فقط روی گوشی خودت (SharedPreferences) می‌ماند و هیچ‌وقت داخل کد یا گیت‌هاب نمی‌رود.

### اوا — AvalAI

1. به `avalai.ir` برو و یک کلید API بساز.
2. ارائه‌دهنده را **اوا — AvalAI** بگذار.
3. Base URL: `https://api.avalai.ir/v1` — داخل ایران اگر باز نشد: `https://api.avalapis.ir/v1`
4. مدل: `gpt-4o-mini`
5. کلید را وارد کن — ذخیره خودکار است، دفعه بعد لازم نیست دوباره وارد کنی.

### لیارا — Liara AI

1. در کنسول لیارا یک سرویس **هوش مصنوعی** و یک کلید API برای Workspace بساز.
2. ارائه‌دهنده را **لیارا — Liara AI** بگذار.
3. **Base URL را دقیقاً همان‌طور که لیارا در کنسول به تو داده کپی کن** — مخصوص Workspace توست.
4. مدل: مثلا `google/gemini-2.5-flash`
5. کلید را وارد کن — ذخیره خودکار است.

### بدون API هم کار می‌کند (آفلاین)

اگر کلید وارد نکرده باشی، این دستورها آفلاین رسم می‌شوند:
«راه‌انداز مستقیم موتور»، «ستاره مثلث»، «چپ‌گرد راست‌گرد»، «آسانسور»،
«درب اتوماتیک»، «پمپ آب»، «سه موتور ترتیبی»، «تایمر و لامپ»، «لامپ».

## بیلد با گیت‌هاب (بدون کامپیوتر و بدون اندروید استودیو)

1. در گیت‌هاب ریپوی `ekts-android` بساز و همه فایل‌های این پروژه را آنجا آپلود کن (پوشه `.github` حتما).
2. به تب **Actions** برو، اجرای **Build Android APK** را باز کن و بعد از سبز شدن،
   از پایین همان صفحه `ekts-debug-apk` را دانلود کن. داخلش `app-debug.apk` است.
3. آن را به گوشی بفرست و نصب کن (نصب از منبع ناشناس را تایید کن).

هر بار که به `main` پوش کنی، یک APK جدید ساخته می‌شود.

### بیلد روی کامپیوتر (اختیاری)

```bash
gradle assembleDebug
# خروجی: app/build/outputs/apk/debug/app-debug.apk
```

نیازمند JDK 17، Gradle 8.7، Android SDK 34 (AGP 8.5.2). زبان پروژه **جاوا** است.

## چطور هوش مصنوعی مدار می‌کشد

برنامه یک System Prompt به مدل می‌دهد که فقط یک JSON برگرداند
(قطعه‌ها، مختصات، سیم‌ها، زمان تایمر). نوع‌های مجاز شامل همه قطعه‌های بالا
به‌علاوه `POWER_3PH, MOTOR_1PH, TIMER_OFF, JOG_NO, RELAY_COIL, BUZZER` است.
برنامه JSON را می‌خواند و مدار را در ویرایشگر رسم می‌کند.

## محدودیت‌های نسخه ۲

- شبیه‌سازی فقط مدار فرمان است؛ محاسبه ولتاژ/جریان نقطه‌به‌نقطه و SPICE ندارد.
- سیم‌کشی دستی است؛ مسیریابی خودکار سیم ندارد.
- کلید API روی گوشی ذخیره می‌شود؛ برای انتشار عمومی برنامه، کلید را به سرور خودت منتقل کن.
- EKTS نام و محصول شرکت دیگری است؛ این برنامه کپی کد آن نیست — یک شبیه‌ساز مستقل با همین ایده کلی است.
